# Data Storytelling Studio

**Category:** More Platforms
**Part of:** AutoMatrixLab

Research findings as films people actually watch

## Overview

A studio I built to turn research findings, reports and scripts into finished films: a Remotion engine, a cached pipeline and a local web app on top, running only on my own machine. Four project types: research music videos, narrated research presentations, project report presentations and promotional videos. A ten-track timeline (audio, lyrics, my video clips, photo beat sequences, screen moments and code, name cards, hook sections, corner equaliser and two overlay tracks) where nothing is ever deleted, so a block taken off is listed under Removed and restorable. Every step hashes its inputs, so editing one lyric re-runs the alignment and never the image work. Built because findings that stay inside journals and reports reach almost nobody.

The clip above is the app being used. The four films it produced are below, and three short clips of the editor at work are on the project page.

Data Storytelling Studio is the system I built to turn findings into films, shaped the way you want the story told.
